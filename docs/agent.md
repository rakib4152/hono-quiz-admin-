## 4. Database Connection Lifecycle in Cloudflare Workers

When executing database operations in route handlers:
1. Instantiate the Drizzle client:
   ```ts
   const db = await createDrizzleClient(c.env);
   ```
2. Run type-safe Drizzle queries:
   ```ts
   const data = await db.select().from(quizzes).where(eq(quizzes.examId, examId));
   ```
3. **Always close the connection in the `finally` block** using `waitUntil`:
   ```ts
   finally {
     c.executionCtx.waitUntil(endDrizzleConnection(db));
   }
   ```
